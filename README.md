# **Challenge del Amigo Secreto | Alura LATAM | Fer Lázaro**

---

### **Descripción del Proyecto**

`Challenge del Amigo Secreto` es un proyecto que sirve como práctica para profundizar en diversas índoles del desarrollo web. He terminado el challenge, es completamente funcional y con todos los requisitos que se me han solicitado. 
El juego consiste en ingresar nombres de amigos que se mostrarán en pantalla como lista. Puedes sortear alguno de ellos para ver el ganador, ¿qué se gana? Ni yo sé, pero fue divertido para mí hacer este tipo de dinámica :).

### **Características**

* **Entrada de Nombres**: El usuario puede agregar fácilmente los nombres de los participantes uno por uno.
* **Gestión de Lista**: La aplicación muestra una lista clara y actualizada de todos los nombres agregados.
* **Sorteo Aleatorio**: Un algoritmo de sorteo asegura que a cada persona se le asigne un amigo secreto de manera completamente aleatoria.

### **Tecnologías Utilizadas**

El proyecto está construido con:

* **HTML5**: Para la estructura y el contenido de la página.
* **CSS**: Para el diseño visual, la tipografía y el estilo general.
* **JavaScript**: Para la lógica de la aplicación, la gestión de nombres, el sorteo y la manipulación del DOM.

### **Cómo Usar**

1.  **Ingresar Nombres**: En el campo de texto, escribe el nombre de un participante y haz clic en el botón **`Añadir`**.
2.  **Ver la Lista**: Cada nombre que añadas aparecerá en la lista de amigos debajo del campo de entrada.
3.  **Realizar el Sorteo**: Una vez que todos los nombres estén en la lista, haz clic en el botón **`Sortear amigo`** para obtener el resultado.
